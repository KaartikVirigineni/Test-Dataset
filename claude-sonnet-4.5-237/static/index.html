🟢 Realtime Presence API

Production-ready REST API for managing realtime user presence and session tracking

Technology Stack

Actix Web (Rust) SQLite JWT Authentication RBAC Docker OpenAPI 3.0

API Documentation

📄 View OpenAPI Specification

Key Endpoints

POST /api/auth/register
Register a new user account
POST /api/auth/login
Login and receive JWT token
GET /api/sessions
List all active presence sessions (authenticated)
POST /api/sessions
Create a new presence session (authenticated)
PUT /api/sessions/{id}
Update session status (online/away/offline)
DELETE /api/sessions/{id}
Delete a presence session
GET /api/users
List all users (admin only)
GET /health
Health check endpoint

Features

  • JWT-based authentication
  • Role-based access control (Admin/User)
  • Realtime presence tracking (online/away/offline)
  • Session metadata support
  • SQLite persistent storage
  • Production-ready with Docker
  • Complete OpenAPI 3.0 documentation
  • CORS enabled
